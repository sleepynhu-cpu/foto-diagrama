# Foto → Diagrama

Lê o texto de fotos de caixas de fusíveis (OCR no próprio navegador), organiza em itens por marca/modelo/ano,
marca a posição de cada fusível e exporta só texto (`diagramas.js` / `diagramas.json`) e imagens SVG das posições.

Os dados ficam salvos só no navegador de quem usa; nada é enviado para servidor.

Site: https://sleepynhu-cpu.github.io/foto-diagrama/
